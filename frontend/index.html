Verdict

This console talks to a transfer-learning image classifier (EfficientNetB0 backbone, fine-tuned on chest radiographs, two stages: frozen backbone then unfrozen fine-tuning) trained to distinguish Normal from Tuberculosis chest X-rays. See training/train.py for the full training pipeline, and app/gradcam.py for the attention-heatmap implementation.

The decision threshold is deliberately set high (94%, not the naive 50%) — chosen with evaluate.py's threshold sweep so the model never trades away a real Tuberculosis case for a lower Normal false-alarm rate. See README.md for the full validation results.

This project is for educational / portfolio purposes and is not a certified medical device.
